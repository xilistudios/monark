# Cloud-storage failure-contract fixture

`auth-failure-contract.json` pins the **byte-exact** failure messages of
Monark's Google Drive auth/refresh/OAuth commands (`AuthFailureClass`, see
`src-tauri/src/commands/errors.rs`) together with the classification the
frontend (`classifyCloudFailure`, `src/services/cloudStorageErrors.ts`) must
derive from each message (issue #28, D4).

The `message` values are **generated by rendering the real Rust templates** —
never hand-edited. If a template, context or provider wording changes,
re-derive the affected `message` from Rust before touching this file.

Consumers (tests only): the TS loader `src/test/helpers/authFailureContract.ts`
(single entry point — tests never import the JSON directly); the Rust
`include_str!` consumer lands with T12, the TS consumer tests with T13.
